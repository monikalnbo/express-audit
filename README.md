# 快递单号比对审查工具

macOS / Windows 双平台桌面工具。导入两份 Excel，按快递单号比对，
单边单号判为异常，具体重量 vs 区间重量模糊比对，异常自动标红并提取。

## 直接使用（已打包版）

双击 `快递比对审查.app`（Mac）或 `快递比对审查.exe`（Windows）即可。

## 从源码运行

```bash
pip install pandas openpyxl        # tkinter 为 Python 自带
python app.py
```

## 打包成独立可执行文件

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 快递比对审查 app.py
# 产物在 dist/ 目录:
#   macOS -> 快递比对审查.app / 可执行文件
#   Windows -> 快递比对审查.exe
```

注意：Mac 包要在 Mac 上打，Windows 包要在 Windows 上打（交叉打包不支持）。

## 使用步骤

1. 选择 A 方表格（具体重量一方）和 B 方表格（区间重量一方）
2. 列名会自动猜测（含"单号/运单"的列 = 单号列；含"重量/区间"的列 = 重量列），可手动改
3. 可选填容差，如 `0.05` 表示 ±50g 内视为一致
4. 点击「开始比对审查」，报告生成在 A 方文件同目录的 `审查报告.xlsx`

## 支持的区间格式（B方）

`1-2`、`0.5~1.5公斤`、`1至2kg`、`小于3`、`不超过2.5`、`大于1`、`3以上`
单位自动识别：g / kg / 吨 / lb，缺省按 kg。

## 报告内容（4 个 sheet）

| Sheet | 内容 |
|---|---|
| 比对明细 | 全部匹配结果及说明 |
| 异常提取 | 仅异常项（重量不符 / 单边缺单） |
| A方标注 | A方数据副本，异常行红色高亮 + 审查备注 |
| B方标注 | B方数据副本，同上 |
